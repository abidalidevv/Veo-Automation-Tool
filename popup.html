User Guide

1. Prepare Google Flow

  1. Open Google Flow and sign in to the Google account that can create videos or images.
  2. Open or create a Flow project, then keep the Flow tab active beside this extension.
  3. Choose a mode in Automation before entering prompts.

2. Choose the correct mode

  • Text to Video: creates a video from each text prompt.
  • Frame to Video: uses a first frame, or first and last frames, for each prompt.
  • Ingredients to Video: attaches matching reference images to each video prompt.
  • Text to Image: creates still images from text prompts.
  • Ingredients to Image: creates images using uploaded references.

3. Add prompts and input images

  1. Separate prompts with one blank line. Each block becomes one queue item.
  2. For Frame or Ingredients modes, upload images before pressing Run.
  3. Use image filenames that appear in the prompt when Auto-add character images is enabled.
  4. Review the prompt preview to confirm the images assigned to every prompt.

4. Configure generation

  • Concurrent Prompts: how many prompts are submitted in one batch. Start with 1 for stability.
  • Random Delay: waiting time between prompts to reduce UI conflicts.
  • Outputs per Prompt: choose 1 to 4 results for each prompt.
  • Model, aspect ratio, and duration: configure them in Setting before running.
  • Save to folder and Auto rename: organize downloaded results automatically.

5. Run the queue

  1. Press Run. The tool selects the Flow mode, attaches images, enters the prompt, and submits it.
  2. Keep the Flow tab open while the queue is running. Do not manually change its mode or composer.
  3. Follow each item in Prompt Queue: preparing, attaching images, submitting, rendering, downloading, or completed.

6. Retry and failure handling

  • A retry is used only when the current render card explicitly shows Not successful.
  • Queued, preparing, or rendering cards are not retried.
  • Max Retries on Failure controls the retry limit. Use a moderate value such as 3 to 5.

7. Downloads and Edge permission

  • Select automatic video/image quality in Setting. Higher resolutions may require the appropriate Google plan.
  • Files are saved under the browser Downloads folder and the selected project subfolder.
  • Full auto Run requests optional debugger permission. If Edge refuses it, leave this option off and use the normal click flow.
  • Reload the extension and refresh Google Flow after installing a new extension version.
